# 10. Identity Layer: Minimal Signature on Landing State

Date: 2026-08-20

## Status
Accepted

## Context
The landing state must decide how much personal identity information is shown before the user selects a sector. More content competes with the globe's visual impact; less is mysterious.

## Decision
**Minimal Identity** on Landing State:
- Only the personal signature line (e.g. `Louis · Developer & Creator`) and a single poetic positioning tagline (e.g. `Building tools that think.`) are shown.
- Social links, full bio, and contact information live inside the Hub Abyss sector (Continent 4), requiring intentional exploration.
- A minimal GitHub icon link may appear discreetly in the corner of the page at all times as a persistent ambient element.

## Consequences
- The globe and its spatial metaphor carry the full visual weight of the landing experience.
- Personal identity is revealed progressively through exploration, matching the "planet to discover" concept.
- Avoids information overload competing with the point-cloud sphere on first impression.
