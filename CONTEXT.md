# Domain Glossary: Louis Editorial Studio Hub (Louis-369.github.io)

## Ubiquitous Language & Core Concepts

### Atmospheric & Layout System
- **Warm Ivory Paper Canvas (米白紙感底蘊)**: Warm cream/off-white background (`#F9F8F5` / `#F3F0EA`) with high-contrast charcoal ink typography (`#121316`, `#2B2D33`).
- **Paper-Cut Framing (剪紙透視相框)**: Editorial card windows with crisp rounded borders, dynamic inner image zoom, and interactive 3D perspective mouse tilt (inspired by `bymonolog.com`).
- **Stacking Cards Pinning (滾動層疊視差)**: As the user scrolls through projects, cards pin smoothly via GSAP ScrollTrigger and stack gracefully over preceding items.
- **Lenis Smooth Engine (慣性平滑滾動)**: Butter-smooth inertial scrolling physics synchronized with scroll-driven animations.
- **Magnetic Kinetic Cursor (磁性動態游標)**: Desktop fluid cursor that expands, displays action labels (`Explore`, `Open`), and snaps magnetically to buttons.

### Core Content Modules
- **Hero Module**: Large display typography, status indicator (`Available for innovative builds`), and subtle ambient webgl/canvas accent.
- **Featured Works / Stories**: Showcase cards for `Mind-Sync`, `Sticker to GIF`, `FitStepSync`, and experimental WIP modules with live metrics and deep-links.
- **About & Philosophy**: Statement section with scroll-driven word/line highlight reveal.
- **Footer Hub**: Persistent contact routing, live local time, and GitHub profile navigation.
